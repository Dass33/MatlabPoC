Help & Documentation

Workflow

  1. Submit — Upload .tiff image files and matching .txt metadata files. Configure algorithm parameters in the sidebar. Click Submit to queue the MATLAB analysis.
  2. Kymograph — View the kymograph PNG images generated by the MATLAB analysis.
  3. Post-processing — Load a completed job, inspect trajectories with the interactive scatter plot (lasso or box-select to mark outliers), adjust per-property σ thresholds, and optionally run iOC calibration. Click Accept & Save to write collection_postprocessed.json.
  4. Population Analysis — Compute statistics (robustMean or Gaussian fit) on the filtered trajectories. Results are saved to population.json.
  5. History — View all jobs, download a ZIP of results, or force-free stuck jobs.

Output Files

config.json
Algorithm parameters used for this job.
collection.mat
Raw trajectory data from MATLAB (HDF5 v7.3 format).
collection_postprocessed.json
Filtered trajectories + iOC calibration (if enabled).
population.json
Population statistics (MEAN, STD, FWHM, RESOLUTION).
kymographs/*.png
Kymograph images, one per experiment file.
matlab.log
MATLAB container stdout/stderr.

Configuration

  • Use the sidebar to adjust all algorithm parameters before submitting.
  • Export the current config as JSON and re-upload it later to restore settings.
  • Worker slots are controlled by the MAX_WORKERS environment variable (default 2).
